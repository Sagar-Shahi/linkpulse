Quick start

Replace YOUR_KEY with a key from above, and the address with your own site.

curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/v1/links/ \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"destination_url": "https://example.com/offer", "utm_source": "newsletter", "utm_medium": "email", "utm_campaign": "november"}'
